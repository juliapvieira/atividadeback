O que é Back-End?

O Back-End é muito importante em uma aplicação Web. Ele recebe as requisições, processa as informações, acessa o banco de dados quando necessário e envia uma resposta para o usuário.

Quando um usuário faz login, realiza uma compra ou envia um formulário, o Back-End recebe essas informações e realiza o processamento.

1. Front-End e Back-End

Front-End

O Front-End é a parte do site que o usuário consegue visualizar e utilizar. Ele envolve elementos como textos, imagens, botões, menus e formulários.

  • HTML
  • CSS
  • JavaScript

Back-End

O Back-End trabalha nos bastidores da aplicação. Ele processa informações, aplica regras de negócio, acessa bancos de dados e envia respostas para o Front-End.

2. Funcionamento do Back-End

Cliente e servidor

O cliente é o navegador ou dispositivo utilizado pelo usuário. O servidor recebe as solicitações e realiza os processos necessários.

Requisição e resposta

A requisição é uma solicitação enviada pelo cliente. Depois de processar a solicitação, o servidor envia uma resposta.

HTTP e HTTPS

HTTP é um protocolo utilizado para a comunicação entre cliente e servidor. HTTPS é a versão segura, que utiliza criptografia para proteger os dados.

Servidor Web

O servidor Web recebe as requisições e envia os arquivos ou informações solicitadas.

Regras de negócio

São regras que determinam como o sistema deve funcionar. Por exemplo, uma loja pode impedir uma compra quando não existe produto disponível no estoque.

Validação de dados

  • Verificar se o e-mail está correto.
  • Verificar se os campos obrigatórios foram preenchidos.
  • Verificar se os dados possuem o formato correto.
  • Verificar informações antes de armazená-las.

O que acontece quando o usuário realiza uma ação?

  1. O usuário realiza uma ação.
  2. O Front-End envia uma requisição.
  3. O servidor recebe a requisição.
  4. O Back-End processa os dados.
  5. O banco de dados pode ser consultado.
  6. O servidor envia uma resposta.
  7. O Front-End apresenta o resultado.

3. APIs

O que é uma API?

API significa Application Programming Interface. Ela permite que diferentes sistemas se comuniquem e troquem informações.

API REST

API REST é uma forma muito utilizada para criar APIs Web. Ela utiliza métodos HTTP para realizar operações.

Endpoints

Endpoint é um endereço utilizado para acessar uma determinada função ou informação de uma API.

Conclusão

O Back-End é uma parte fundamental das aplicações Web. Ele é responsável por receber requisições, processar informações, aplicar regras, trabalhar com bancos de dados e enviar respostas para o usuário.

Dessa forma, quando clicamos em um botão em um site, pode existir uma série de processos acontecendo no servidor antes que o resultado apareça na tela.

Quando o usuário clica em um botão no site, o que está acontecendo no Back-End?

Quando o usuário clica em um botão, o Front-End pode enviar uma requisição para o Back-End. O servidor recebe essa requisição, processa os dados, pode consultar um banco de dados e depois envia uma resposta para o Front-End. O resultado então aparece para o usuário.
